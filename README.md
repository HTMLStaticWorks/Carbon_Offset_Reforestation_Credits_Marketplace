## Features
- **Design System**: Tailored eco-architectural palette with CSS variables for seamless light/dark modes.
- **Bidirectional RTL Support**: Global RTL toggle with dedicated `rtl.css` directional rules.
- **Responsive Navigation**: Full horizontal desktop menu and animated slide-out mobile drawer (≤1024px).
- **Animations**: GSAP staggering reveals, scroll triggers, and smooth hover effects.
- **Brand Favicon**: Custom vector SVG favicon (`favicon.svg`) with high-contrast squircle badge and biophilic leaf emblem, rendering crisply across dark and light browser tabs.
- **Interactive Tools**: Built-in Carbon & Energy Savings Calculator, Project Filter Tabs, Species Explorer, FAQ Accordions, and Instant Budget Estimators.

## Usage
Simply open `index.html` in your browser. All styles, icons (Phosphor via CDN), and GSAP animations load directly.
